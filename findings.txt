water test is useless, only 1 occurence. tells us nothing

modal purity is essentially measuring the fraction of a token's occurrences falling in its single most common cluster. we see a relatively low purity, which implies that the lexical meaning is not enough, the embedding is not enough to tell us where it lies. so the local texture of the tokens around it dictate where it sits. needs some investigation. there is hidden contextual informaiton that we need to unearth. 

also since the test size is tiny, i expect this to increase on a larger test size. since the tokens that acutally pass on a small test size would be the 'the', 'an' and other super common tokens. so there is some bias here. 

so contextual clustering is probably the precndition for the graph sicne we are seeing a signal that the embedding adn the position both are not enough to predict the cluster this key will lie in. so the next hurdle is being able to capture contextual informatio nin the clustering alogirthm. pretty hard
